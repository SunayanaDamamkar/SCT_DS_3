# Project Title
Customer Purchase Prediction using Decision Tree Classifier
# Description
This project focuses on building a Decision Tree Classifier to predict whether a customer will purchase a product or service based on demographic and behavioral data. The project uses the Bank Marketing Dataset from the UCI Machine Learning Repository and applies machine learning techniques to analyze customer responses.

The dataset includes customer information such as age, job, marital status, education, balance, loan details, contact type, and previous marketing campaign outcomes. Using data preprocessing and classification techniques, the model predicts whether a customer is likely to subscribe to a term deposit.
